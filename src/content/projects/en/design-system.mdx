## Problem

Every team re-implemented buttons, modals and forms their own way. The result was an inconsistent interface and the same accessibility bugs in many places.

## Solution

A single component library, with color, spacing and type tokens exported from Figma and consumed as CSS variables.

## Technical decisions

- Focus rings come from a token, so they behave the same everywhere.
- Storybook docs with automated accessibility checks on every story.
- Semantic versioning and a changelog generated from commits.

## Outcome

New screens are now assembled from the library, and contrast and focus issues stopped showing up in reviews.
