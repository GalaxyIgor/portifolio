## Problem

Spending spreadsheets are hard to read on a phone and don't show trends over time.

## Solution

A dashboard that imports a bank CSV, categorizes entries and shows how each category evolves over time.

## Technical decisions

- Data cached with TanStack Query and persisted to IndexedDB so it works offline.
- Charts ship with an equivalent text description for screen readers.
- Filters live in the URL, so any view can be shared.

## Outcome

A dashboard that opens fast on a phone and responds without reloading the page.
